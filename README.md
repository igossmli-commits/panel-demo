# Panel Full Stack Demo

Proyecto web estático utilizado en el laboratorio de Desarrollo Full Stack para practicar:

- trabajo local en Visual Studio Code;
- control de versiones con Git;
- repositorios remotos en GitHub;
- ramas y commits;
- colaboración mediante Pull Request;
- publicación con GitHub Pages.

## Archivos

- `index.html`: estructura principal de la página.
- `styles.css`: presentación visual y diseño responsivo.
- `app.js`: interacción del botón de verificación.
- `.gitignore`: exclusiones básicas para el repositorio.

## Ejecución local

Con Node.js y npm disponibles:

```cmd
npx --yes http-server . -p 5500
```

Luego abrir:

`http://localhost:5500`
